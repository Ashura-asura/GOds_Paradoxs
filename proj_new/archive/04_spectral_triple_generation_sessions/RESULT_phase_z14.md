# Phase Z14 — Rule 9 audit of the Z6–Z13 line, and synthesis with
# Theorem B-3 (this session)

## Question

Two things this project's own methodology (`GROUND_RULES.md` Rule 9,
`docs/POST_AUDIT_TARGET.md`) requires before Z6–Z13's results can be
recorded as anything more than an internally-consistent side
calculation:

1. **Is the `su(3)_F` used throughout Z6–Z13
   (`build_su3f_generators()` — the standard Gell-Mann basis) actually
   the same object as the `SU(3)_f` that Phase A2 derives as part of
   the `E8 -> E6 x SU(3)_f` branching used to get 3 generations, or is
   it an independently-assumed stand-in that happens to share a name?**
   If it's the latter, Z6–Z13 is a conditional statement ("if some
   `su(3)` flavor gauge symmetry exists, then...") that hasn't been
   connected to Cl(10)xE8 at all — exactly the failure mode
   `POST_AUDIT_TARGET.md` Section E warns about.
2. **Does this project already have a relevant prior result that
   bears on Z6–Z13's conclusion, which needs to be netted against it
   rather than treated as if Z6–Z13 were operating in a vacuum?**
   Specifically: `docs/ALL_THEOREMS.md`'s **Theorem B-3** (established
   well before the Z-series) already proved that a minimal single-
   triplet `SU(3)_f` flavon potential has its minimum forced to
   `ε=0` — i.e., minimal `SU(3)_f`-breaking dynamics in this framework
   doesn't actually break the symmetry.

## Method / argument

**Part 1 — is Z6–Z13's `su(3)_F` the real one?**

Checked Phase A2's own output: `248 = (78,1) + (1,8) + (27,3) +
(27bar,3bar)` under `E6 x SU(3)_f` is confirmed dimensionally in
`phase_a2_e8_core.py`. The `(1,8)` piece is the adjoint of `SU(3)_f`
sitting *inside E8's own 248-dimensional gauge sector* — so `SU(3)_f`
is not an add-on group with no gauge bosons; it has literal gauge
bosons among E8's 248, on the same footing as every other gauge boson
in this framework. The order-one condition (an NCG statement about
fluctuations by elements of a *genuinely gauged* algebra) is therefore
a legitimate thing to ask about `SU(3)_f` specifically, not a category
error.

Separately: the 3 generations sit in the `3` of `SU(3)_f` (that's what
"`(16,3)`" in Phase A2's branching means — 3 copies of the `16`,
transforming as the fundamental of `SU(3)_f`). Representation theory
of `su(3)` says the 3-dimensional fundamental representation is unique
up to unitary change of basis (and the `3` vs `3-bar` choice, which
only affects which of a generator/its negative-transpose is used, not
the invariant-theory content of Sym²/Λ² decompositions used
throughout Z9–Z13). The standard Gell-Mann matrices used in
`build_su3f_generators()` **are** the fundamental representation, in
one particular basis. Since Z9–Z13's actual results (which real
`SU(3)_f)`-irreps of `Y_gen` survive the order-one condition) are
basis-independent representation-theoretic statements — Schur's-lemma
type conclusions about which pieces of `Sym²(3)`/`Λ²(3)` are
invariant — a change of basis on the generators cannot change the
answer. **Conclusion: Z6–Z13's `su(3)_F` is not merely "a" flavor
symmetry — up to the basis-independence just argued, it is Phase A2's
actual, gauged `SU(3)_f`.** This is checked, not assumed: the
dimensional confirmation of `(1,8)` inside 248 is Phase A2's own
existing output, re-examined here for a purpose Phase A2 didn't use it
for.

**Part 2 — netting against Theorem B-3.**

Theorem B-3 (`phase_b_structural_limits.py`, restated as "New Theorem
1"): for a single flavon in the `3` of `SU(3)_f`, the most general
`SU(3)_f`-invariant potential is a function of the one invariant
`I2 = φ†φ` alone (the invariant ring of a single `3` under `SU(3)` is
generated by that one quadratic invariant — standard invariant
theory, not new to this phase). Minimizing `V(I2)` over the physical
modulus `ε` (the would-be symmetry-breaking direction) forces
`dV/dε=0 => ε=0` **regardless of the specific form of `V`** — the
invariant ring simply doesn't contain a direction for `ε` to run in
that the potential could prefer away from zero. **The dynamically
preferred vacuum of a minimal single-triplet `SU(3)_f`-breaking sector
is the unbroken one.**

Putting the two together, for the first time in this project (Theorem
B-3 predates the Z-series; nothing in `phase_b` or anywhere else
connects it to the order-one/Yukawa-texture question — that
connection is what this phase adds):

> **In this framework, with `SU(3)_f` recognized as Phase A2's actual
> gauged flavor symmetry (Part 1) and a minimal single-triplet flavon
> as the only tested `SU(3)_f`-breaking sector (Theorem B-3): the
> dynamically preferred vacuum has `SU(3)_f` unbroken, and an unbroken
> `SU(3)_f` forces the symmetric-channel Yukawa couplings to be
> exactly generation-blind (`Y_gen ∝ I_3`, Z9/Z10) and the
> antisymmetric-channel Yukawa to vanish exactly (Z9/Z10, confirmed
> exactly in Z13). Chaining these: minimal Cl(10)xE8, if `SU(3)_f` is
> gauged per the branching Phase A2 already uses to get 3 generations,
> and if the flavon sector stays minimal, does not merely fail to
> derive the fermion mass hierarchy — it dynamically *predicts* the
> wrong answer (degenerate or zero Yukawa couplings), which is directly
> excluded by the observed `m_t : m_c : m_u` hierarchy and nonzero CKM
> mixing.**

## Verdict — L1 (synthesis of two already-L1 results; no new numerical
computation, but a new, previously-unmade connection between them)

This is a genuine structural-failure result, Rule 8: not "this
mechanism doesn't help," but "this mechanism, taken on its own stated
terms and combined with an already-established result in this same
project, actively predicts an excluded outcome." That's a stronger and
more useful statement than either Theorem B-3 or Z9–Z13 makes alone,
and it directly serves `docs/POST_AUDIT_TARGET.md`'s repeated
instruction to check new work against `docs/MECHANISM_FAILURE_MAP.md`
before it gets recorded as progress.

**Explicit Rule 9 self-check on Z6–Z13, per `POST_AUDIT_TARGET.md`
Section E's own instruction to apply this "the moment any candidate
D_F is proposed":** would the order-one construction have plausibly
found a *different* survivor if `SU(3)_f`'s representation content
were different (e.g. if the branching had put the generations in the
adjoint `8` instead of the fundamental `3`)? Yes — the Sym²/Λ²
decomposition, and therefore which pieces survive, is representation-
specific; a different representation would give a different (and in
general nonzero-dimensional, non-identity) answer. This is real
discriminating power, not a construction rigged to reproduce a
preordained answer — it passes Rule 9.

**What this phase does NOT establish, stated plainly:**

- It does not prove no non-minimal `SU(3)_f`-breaking sector can work
  — only that the single-triplet minimal one, already on record as
  Theorem B-3, is now known to combine with Z9–Z13 into an excluded
  prediction rather than a merely-unconstrained one. A two-flavon, an
  `SU(3)_f`-adjoint-representation flavon, or some other non-minimal
  sector might evade Theorem B-3's `ε=0` result — untested here, and
  its own parameter count (per `POST_AUDIT_TARGET.md`'s repeated
  "net against the target" instruction) would have to be counted
  against whatever Z9–Z13 saves before calling it progress.
- Phase A2's own output notes minimal `248` contains no `126_H`
  (`"No 126 Higgs in 248 (requires 3875 representation)"`) — so the
  `M126` channel result from Z9–Z13, while a correct statement about
  Cl(10)'s general Higgs-representation structure (Phase X's scope),
  may not even be a live channel in the *minimal-248* version of this
  framework specifically. This phase's argument goes through cleanly
  for `M10` (which *is* in minimal 248) on its own; the `M120`/`M126`
  parts inherit whatever status those channels have elsewhere in the
  project (Phase X's non-minimal-248 scope) and shouldn't be read as
  automatically about the minimal-248 model.
- This does not change Theorem B-3's own status or proof — it is
  reused verbatim, not re-derived.
